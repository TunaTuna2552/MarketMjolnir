## 1. Verificación Manual de Cálculos Financieros e Inventario (Datos de Prueba)

Antes de la matriz completa, se documentan las operaciones aritméticas verificadas manualmente con referencias del catálogo inicial:

1. **Caso Compra con Envío Estándar (`Subtotal < $150.000 COP`):**
   - Producto seleccionado: `PROD-005` (*Termo Deportivo Berserker 1L*) -> Precio unitario = $\$42.000\text{ COP}$.
   - Cantidad = $2\text{ unidades}$.
   - $\text{Subtotal} = 2 \times \$42.000 = \$84.000\text{ COP}$.
   - Como $\$84.000 < \$150.000$, $\text{Envío} = \$8.000\text{ COP}$.
   - $\text{Total} = \$84.000 + \$8.000 = \$92.000\text{ COP}$. (**Verificado: Exacto**).

2. **Caso Compra con Envío Gratis (`Subtotal >= $150.000 COP`) y Descuento de Stock (`10 -> 7`):**
   - Producto seleccionado: `PROD-001` (*Audífonos Bluetooth Valhala Pro*) -> Precio unitario = $\$85.000\text{ COP}$, Stock inicial = $10\text{ unidades}$.
   - Cantidad = $3\text{ unidades}$.
   - $\text{Subtotal} = 3 \times \$85.000 = \$255.000\text{ COP}$.
   - Como $\$255.000 \ge \$150.000$, $\text{Envío} = \$0\text{ COP (GRATIS)}$.
   - $\text{Total} = \$255.000 + \$0 = \$255.000\text{ COP}$.
   - Al confirmar compra: $\text{Stock final en catálogo} = 10 - 3 = 7\text{ unidades}$. (**Verificado: Exacto**).

3. **Caso Aplicación de Cupón `BIENVENIDO10` (`10% de descuento`):**
   - Carrito con $1\text{ unidad}$ de `PROD-001` ($\$85.000$) + $1\text{ unidad}$ de `PROD-003` ($\$32.000$).
   - $\text{Subtotal} = \$85.000 + \$32.000 = \$117.000\text{ COP}$.
   - $\text{Descuento } (10\%) = \$117.000 \times 0.10 = \$11.700\text{ COP}$.
   - $\text{Envío} = \$8.000\text{ COP}$ (porque subtotal $\$117.000 < \$150.000$).
   - $\text{Total} = (\$117.000 - \$11.700) + \$8.000 = \$105.300 + \$8.000 = \$113.300\text{ COP}$. (**Verificado: Exacto**).
